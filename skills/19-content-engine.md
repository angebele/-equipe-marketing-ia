# Skill 19 — Content Engine

## Objectif

Transformer un socle d'histoires et de convictions en système de
production de contenu durable, plutôt que de chercher une idée de post à
chaque fois.

## Utilisé par

- 🎭 Conteur de Marque

## Framework — Les 3 couches du moteur

### Couche 1 — Le socle narratif
Les 5 à 10 histoires fondatrices identifiées (Story Mining), chacune
réutilisable sous plusieurs angles.

### Couche 2 — Les formats de déclinaison
Pour chaque histoire, lister les formats possibles : post texte,
carrousel, légende courte, story, newsletter, hook vidéo.

### Couche 3 — Le calendrier de rotation
Un système qui répartit les histoires dans le temps pour éviter de tout
raconter d'un coup ou de se répéter trop tôt.

## Méthode

1. Lister le socle narratif disponible
2. Pour chaque histoire, identifier 2 à 3 angles différents
   (ex : l'angle "échec", l'angle "leçon", l'angle "avant/après")
3. Répartir sur un calendrier en évitant de répéter le même angle deux
   semaines de suite
4. Transmettre au Content Strategist pour intégration dans le calendrier
   éditorial

## Format de livrable

```
MOTEUR DE CONTENU — [Date]
---
SOCLE NARRATIF (histoires disponibles) :
1. [Histoire] → Angles possibles : [...]
2. [Histoire] → Angles possibles : [...]

PLAN DE ROTATION (4 semaines) :
Semaine 1 : [Histoire + angle + format]
Semaine 2 : [Histoire + angle + format]
...

JE TRANSMETS AU CONTENT STRATEGIST :
[Ce qui doit entrer dans le calendrier éditorial]
```

## Exemple court

> **Histoire "le dimanche soir du brouillon supprimé" :** Angle 1 = leçon
> sur l'authenticité (semaine 1, post texte) ; Angle 2 = avant/après de
> l'écriture (semaine 3, carrousel) ; Angle 3 = confession vulnérable
> (semaine 6, story). → Une seule histoire alimente 3 contenus espacés
> sans se répéter.
