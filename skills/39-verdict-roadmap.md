# Skill 39 — Verdict & Roadmap Complète

## Objectif

Synthétiser tous les findings précédents dans un **verdict nuancé** (pas
juste "oui/non") qui dit exactement quel type d'idée c'est, et livrer une
**roadmap de lancement** prête à exécuter en 3 phases.

## Utilisé par

- 🎲 Évaluateur d'Idées

## Framework — Verdict nuancé

### Types de verdict possibles

**✅ OUI — Extension naturelle**
→ Même cible, nouvelle offre cohérente avec ton brand
→ Comment l'intégrer sans confusion

**⚠️ OUI — Pivot léger**
→ Même valeur fondamentale, cible élargie
→ Ajuste le messaging comme ça, risque dilution faible

**🔴 OUI — Pivot majeur**
→ Changement de direction significatif
→ Options : (1) Rebrander totalement (2) Créer une sous-marque (3) Créer un alias / structure séparée

**✅ OUI — Multi-cible viable**
→ Tu gardes cible 1 ET tu ajoutes cible 2
→ Voici comment rester clair, ressources, risques, cross-sell

**⚠️ À REFORMULER**
→ L'idée tient mais il faut changer [la cible / le timing / l'offre]
→ Idée reformulée : [...]

**❌ NON — Ça dilue trop**
→ Pourquoi : c'est trop loin de ton positionnement existant
→ Alternative à considérer : [...]

## Roadmap en 3 phases

### Phase 1 — MVP & Validation (semaines 1-2 ou 1-4)
- Quoi : le test rapide qu'on lance
- KPI : ce qu'il faut prouver
- Go/No-Go : quand décider

### Phase 2 — Validation marché (1-3 mois)
- Quoi : élargissement du test avec segment plus large
- Mesurer : conversions, feedback, alignement avec hypothèses
- Ajustements : A/B tests si nécessaire

### Phase 3 — Lancement complet (2-8 mois après phase 2)
- Scale : comment tu vas de 50 clients à 500
- Messaging : adaptations par cible si multi-cible
- KPI de succès : année 1, qu'est-ce qui te dit "ça marche"

## Format de livrable

```
VERDICT & ROADMAP — [Idée]
---
✅ VERDICT GLOBAL
[Type de verdict : extension / pivot léger / pivot majeur / multi-cible / À REFORMULER / NON]

POURQUOI CE VERDICT :
[Synthèse des trouvailles clés qui justifient le verdict]

SI PIVOT MAJEUR — OPTIONS DE STRUCTURATION :
1. Rebrander complètement
2. Créer une sous-marque
3. Créer un alias / structure séparée

SI MULTI-CIBLE — COMMENT RESTER CLAIR :
[Messaging / Positioning / Ressources / Risques]

---

🚀 ROADMAP DE LANCEMENT

**PHASE 1 — MVP & Validation (Semaines 1-2)**
Durée : [X semaines]
Budget : [X€]
Qui : [Responsable]
Quoi : [Description du test]
├─ Segment cible : [Qui]
├─ Outils : [Avec quoi]
└─ Effort : [Combien d'heures]

KPI DE GO/NO-GO :
✅ GO si : [Métrique 1 atteint X]
⚠️ PIVOT si : [Autre résultat]
❌ NO-GO si : [Pire cas]

Décision à prendre : [Date limite]

---

**PHASE 2 — Validation Marché (1-3 mois après Phase 1)**
Durée : [X mois]
Budget : [X€]
Segment : [Élargir à combien de personnes]
Mesurer :
├─ Conversions (target : X%)
├─ Satisfaction / NPS
├─ Feedback marché sur messaging

Ajustements testés : [A/B tests si nécessaire]

Go/No-Go Phase 3 : [Critères de décision]

---

**PHASE 3 — Lancement Complet (2-8 mois après Phase 2)**
Durée : [Timeline]
Budget : [X€]
Scale :
├─ De X clients à Y clients
├─ Channels : [Comment les acquérir]
├─ Messaging : [Par cible si multi-cible]

KPI Année 1 :
├─ Revenue : X€
├─ Clients : Y

---

📋 LES 3 PROCHAINS PAS (cette semaine)
1. [Action immédiate — tu peux le faire mardi]
2. [Qui valider / par qui avant Phase 1]
3. [Réserver slot calendrier Phase 1]
```

## Exemple court

> **Verdict :** ✅ OUI Extension naturelle. Même cible (expertes), même valeur
> (structure), offre complémentaire. Risque dilution : aucun.
> 
> **Phase 1 (2 semaines) :** Page de vente + 200€ ads. Target : 8% CTR. KPI go :
> >5% CTR. Décision : jour 14.
> 
> **Phase 2 (4 semaines) :** Si go, élargir à 50 prospects. Mesurer conversion.
> Cible : 5% conversion minimum.
> 
> **Phase 3 (3 mois) :** Scale à 200 clients. Revenue cible année 1 : 400K€.
> Break-even : mois 4.
> 
> **3 prochains pas :** (1) Valider messaging avec Copywriter (2) Valider UX
> avec Neuromarketing (3) Réserver slot dev pour mardi.
