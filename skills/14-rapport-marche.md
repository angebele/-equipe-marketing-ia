# Skill 14 — Rapport mensuel de marché

## Objectif

Produire une synthèse mensuelle du marché en une page. Actionnable en
5 minutes de lecture.

## Utilisé par

- 🔍 Veilleur Stratégique
- 👑 Stratège CMO

## Framework — Structure du rapport

### En-tête
- Mois analysé
- Secteur : celui du contexte projet (ex : Coaching / Branding /
  Solopreneurs France)
- Niveau d'activité marché : 🔴 Forte activité / 🟠 Normale / 🟡 Calme

### 1. Ce qui a changé ce mois-ci (3 points max)
Faits nouveaux, lancements concurrents, tendances émergentes.

### 2. Ce qui performe chez les concurrents
Contenus, offres, formats qui ont bien marché.

### 3. Ce que la cible dit en ce moment
Douleurs exprimées, questions posées, frustrations récurrentes.

### 4. Opportunités du mois
Ce qu'on peut exploiter immédiatement.

### 5. Alertes
Ce qui menace, ce qu'un concurrent fait et qu'on doit surveiller.

### 6. Recommandations pour l'équipe
```
CMO → [Action stratégique]
Content → [Sujet à traiter]
Copywriter → [Angle à tester]
Media Buyer → [Opportunité ads]
```

## Règles de format

Une page maximum. Bullet points. Pas de blabla.
Chaque point doit répondre à : **"Et donc, on fait quoi ?"**

## Format de livrable

```
RAPPORT DE MARCHÉ — [Mois] — [Secteur]
NIVEAU D'ACTIVITÉ : [🔴 / 🟠 / 🟡]
---
[Les 6 sections, en bullet points]
```

## Exemple court

> **5. Alertes :** Concurrent X a lancé une offre groupe à 490€ ciblant les
> expertes établies — risque de confusion avec notre programme premium.
> **Et donc :** ne pas baisser le prix ; renforcer la différenciation
> "individuel + diagnostic" dans le contenu des 2 prochaines semaines.
> → Copywriter : angle "le groupe te noie, l'individuel te révèle".
