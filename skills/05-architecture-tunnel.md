# Skill 05 — Architecture de tunnel

## Objectif

Concevoir le schéma complet d'un tunnel de vente : chaque étape, son objectif
unique, ses contenus clés et sa logique technique — du premier contact à la
vente.

## Utilisé par

- 🔧 Architecte Tunnel
- 👑 Stratège CMO

## Framework — Les 6 étapes

### 1. Source de trafic
D'où vient le prospect : contenu organique, ads, bio Instagram, bouche-à-oreille.
Le message d'entrée doit être cohérent avec la suite du tunnel.

### 2. Opt-in (page de capture)
- Un seul objectif : récupérer l'email contre un lead magnet de valeur
- Promesse claire + formulaire minimal (prénom + email)
- Objectif de conversion : > 30%

### 3. Page de remerciement
- Confirmer la livraison + donner l'étape suivante
- Opportunité sous-exploitée : y placer une vidéo de présentation ou une
  proposition d'appel découverte

### 4. Séquence email
- 7 emails (voir skill 04) qui nurturent et qualifient
- Automatisée, déclenchée à l'opt-in, avec tags par comportement

### 5. Page de vente (ou page de candidature)
- Structure en 12 sections (voir skill 03)
- Pour une offre premium : préférer formulaire de candidature + appel
  stratégique plutôt que paiement direct

### 6. Confirmation
- Confirmer l'action, réduire le doute post-décision
- Donner les prochaines étapes concrètes (préparation de l'appel, accès, agenda)

## Règles

- Un tunnel = un objectif = une cible prioritaire
- Chaque page a UN seul CTA
- Mobile first à chaque étape
- Mapper chaque étape sur l'outil du projet (voir Stack outils du contexte)

## Format de livrable

```
TUNNEL : [Nom]
OBJECTIF : [Résultat attendu]
CIBLE PRIORITAIRE : [Profil]
---
SCHÉMA : [Source] → [Opt-in] → [Merci] → [Emails] → [Vente] → [Confirmation]

DÉTAIL PAR ÉTAPE :
[Pour chaque étape : objectif, contenu clé, CTA, email déclenché, KPI cible]
---
CONFIGURATION TECHNIQUE : [Instructions pour l'outil du projet]
```

## Exemple court

> **Tunnel "Appel Découverte Premium" :** Post Instagram (qualifier) →
> Page de capture "Diagnostic Positionnement offert" (opt-in > 30%) →
> Page merci avec vidéo 2 min + lien calendrier → Séquence 7 emails →
> Page candidature → Appel stratégique → Offre personnalisée.
> Recommandé pour une offre coaching premium : la candidature filtre et
> élève la valeur perçue.
