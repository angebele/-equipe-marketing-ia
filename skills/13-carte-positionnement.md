# Skill 13 — Carte de positionnement

## Objectif

Visualiser où se placent les concurrents sur le marché et identifier les
espaces libres à occuper.

## Utilisé par

- 🔍 Veilleur Stratégique
- 👑 Stratège CMO

## Framework — Méthode en 5 étapes

### Étape 1 — Lister les acteurs
Identifier 5 à 10 concurrents directs et indirects dans le secteur du
contexte projet.

### Étape 2 — Définir les axes de comparaison
Choisir 2 axes pertinents selon le projet. Exemples :
- Axe X : Prix bas ←→ Prix élevé
- Axe Y : Généraliste ←→ Ultra-spécialisé
- Axe X : Méthode ←→ Transformation
- Axe Y : Débutant ←→ Expert confirmé
- Axe X : Volume (beaucoup de clients) ←→ Premium (peu de clients)
- Axe Y : Autonomie ←→ Accompagnement intensif

### Étape 3 — Placer chaque concurrent sur la carte

### Étape 4 — Identifier les zones vides
Les espaces non occupés = opportunités de positionnement.

### Étape 5 — Recommander la position optimale
Où se placer pour être différent ET désirable pour la cible.

## Format de livrable

```
CARTE DE POSITIONNEMENT — [Secteur]
DATE : [Date]
---
AXES CHOISIS :
X : [Axe horizontal]
Y : [Axe vertical]

PLACEMENT DES CONCURRENTS :
[Concurrent 1] → Position : [Description]
[Concurrent 2] → Position : [Description]
...

ZONES LIBRES IDENTIFIÉES :
Zone 1 : [Description] → Opportunité : [Potentiel]
Zone 2 : [Description] → Opportunité : [Potentiel]

RECOMMANDATION DE POSITIONNEMENT :
[Où se placer et pourquoi]

RISQUE :
[Ce qu'il faut éviter]
```

## Exemple court

> **Axes :** X = Volume ←→ Premium, Y = Promesse de visibilité ←→ Promesse
> de structure. **Constat :** 8 concurrents sur 10 se massent dans le
> quadrant Volume + Visibilité ("plus d'abonnés, plus de vues").
> **Zone libre :** Premium + Structure — exactement le territoire
> "transformer le flou en structure" du contexte projet. Recommandation :
> assumer ce quadrant sans jamais glisser vers les promesses de viralité.
